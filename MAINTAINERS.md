# Maintainers

`@fathym/ioc` is maintained by [Fathym](https://github.com/fathym). These people review changes,
cut releases and answer reports:

| Maintainer                          | Role                      |
| ----------------------------------- | ------------------------- |
| [mcgear](https://github.com/mcgear) | Lead maintainer, releases |

## Response times

| What            | First response                      |
| --------------- | ----------------------------------- |
| Security report | Within 3 business days              |
| New issue       | Triaged within 5 business days      |
| Pull request    | First review within 5 business days |

"Triaged" means labeled, and either answered or given a next step. Fixes for security issues and
for regressions in the latest 1.x release come first.
